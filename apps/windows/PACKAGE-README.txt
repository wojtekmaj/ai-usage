AI Usage for Windows 11
=======================

1. Extract the entire ZIP to a writable folder.
2. Start "AI Usage.exe". Keep all files together.
3. If Windows SmartScreen warns about the unsigned app, choose More info, then Run anyway.
4. The app runs in the system tray. Windows may initially put its provider icons in the
   overflow menu (^). Drag the icons next to the battery if you want them always visible.

Left-click any provider icon for the compact usage panel. Right-click for Refresh,
Settings, and Quit. Preferences and logs are stored in %LocalAppData%\AI Usage.
The GitHub Copilot OAuth token is stored in Windows Credential Manager.

This portable build does not require Visual Studio, the .NET runtime, or the Windows App
SDK runtime to be installed separately.
